# Account documents

Place account-specific notes here for sharing and conversion.

## Horizon BCBS UEBA POC MAP

Copy your Obsidian note to:

```text
docs/accounts/Horizon Blue Cross Blue Shield — UEBA POC MAP.md
```

Then commit and push. A Cloud Agent can convert it to DOCX with:

```bash
python3 scripts/md_to_docx.py "docs/accounts/Horizon Blue Cross Blue Shield — UEBA POC MAP.md"
```

Output is written alongside the source file as a `.docx`.
