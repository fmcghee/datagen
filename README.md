# ES POV Customer Demo — Obsidian Vault

Standalone Obsidian vault branch. `.git` is at the vault root so **Obsidian Git** works.

## Clone

```bash
git clone --branch obsidian-vault --single-branch https://github.com/fmcghee/datagen.git es-pov-customer-demo
```

Open `es-pov-customer-demo` in Obsidian. Start at **ES POV Customer Demo Guide.md**.

## Update

```bash
git pull
```

Full datagen repo (scripts, ServiceNow data): `main` branch.
